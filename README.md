# Retro Puzzle Game (Phaser.js)

A mobile-friendly HTML5 game with 7 scenes using Phaser 3:

1. Start screen with a Play button
2. Puzzle 1 (Point-and-click, placeholder)
3. Puzzle 2 (Flying coins, placeholder)
4. Puzzle 3 (Draw image, placeholder)
5. Puzzle 4 (Blank)
6. Puzzle 5 (Blank)
7. Result/Score screen (Blank)

## How to Run

Just open `index.html` in your browser (mobile or desktop, landscape recommended).
